
### 🏆 核心项目定义

* **项目名**：《StoryFlow：人机协同叙事中的语义流演化与创意熵可视化研究》
* **核心逻辑**：
* **Flow (流)**：AI 写的很顺滑（语义距离小），人类写的很跳跃（语义距离大）。
* **Entropy (熵)**：AI 的创新是收敛的（越写越没劲），人类的创新是发散的（惊喜不断）。


* **终极产出**：**1个 Web 互动平台 + 1篇 IEEE 格式论文**。

### 🗺️ 团队作战地图 (Roadmap)

我们把任务拆解为 **3 条并行战线**，每个人只需关注自己的 KPI：

#### 🛠️ 战线 A：数据与算法 (成员 C 主攻)

**任务**：把老师那堆乱七八糟的 Excel 变成漂亮的数学图表。

1. **数据清洗**：
* 运行我给您的 Python 脚本，生成 `evolution_data.json` (演化树) 和 `creativity_data.json` (箱线图)。


2. **特征计算 (核心)**：
* **Embedding**：调用 API 把每句话变成 1536维向量。
* **Flow**：算前后两句话的 Cosine Similarity（余弦相似度）。
* **Entropy**：算“当前句”到“故事语义中心(Centroid)”的 Euclidean Distance（欧氏距离）。


3. **产出**：
* 论文需要的 3 张核心图表（箱线图、折线图、散点图）。
* 给前端用的 `analyzed_story.json` 数据包。



#### 💻 战线 B：Web 系统开发 (成员 A & B 主攻)

**任务**：做一个看起来很“赛博朋克”的网页，能动就行。

1. **左侧交互区**：
* 简单的聊天窗口，“你一句，AI 一句”。


2. **右侧可视化区 (得分点)**：
* **动态心电图**：每写一句，图表跳一下，显示“当前连贯性得分”。
* **演化树展示**：直接加载成员 C 洗好的 `evolution_data.json`，展示一个静态的“人类 vs AI 进化树”。


3. **产出**：
* 可运行的本地 Demo，用于录制演示视频。



#### 📄 战线 C：学术论文 (成员 D 主攻)

**任务**：把大家做的事包装成“实证美学研究”。

1. **填空式写作**：
